# Structure visuelle

## Titre

Gate de couverture Vitest pour les PR vers main

## Bloc 1 — Problème

Texte : « Tests unitaires sans seuil de couverture ».

Visuel : document de PR avec un petit bouclier en contour.

## Bloc 2 — Solution

Texte : « @vitest/coverage-v8 » et « npm run test:coverage ».

Texte : « Gate CI : PR → main ».

Texte : « Seuils : 95 % statements · 85 % branches · 100 % fonctions · 100 % lignes ».

Visuel : engrenage ou terminal relié à une porte de contrôle.

## Bloc 3 — Résultat vérifié

Texte : « 78 tests réussis ».

Texte : « 95,42 % · 85,26 % · 100 % · 100 % ».

Texte : « npm run check : OK ».

Visuel : coche et mini tableau de métriques.

## Flux

Problème → Solution → Résultat vérifié.
